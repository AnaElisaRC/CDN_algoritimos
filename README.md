💻 Algoritmos e Estrutura de Dados / Inteligência Computacional

Este repositório reúne os materiais de aula, exercícios e atividades práticas desenvolvidos nas disciplinas de Algoritmos e Estruturas de Dados (AED1 e AED2) e Inteligência Computacional do curso de Tecnologia em Ciência de Dados para Negócios da FATEC Votorantim.

O conteúdo abrange os fundamentos de lógica de programação, estruturas de dados, algoritmos e introdução à Inteligência Computacional, utilizando cadernos práticos em Google Colab / Jupyter Notebooks.
